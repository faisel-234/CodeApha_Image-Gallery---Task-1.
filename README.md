Image Gallery

A responsive and interactive Image Gallery built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship – Task 1.

Features
📸 Responsive image gallery
🔍 Category-based image filtering
🖼️ Interactive lightbox/image preview
⌨️ Keyboard-accessible interactions
📱 Responsive design for different screen sizes
🎨 Clean and user-friendly interface

Technologies Used
HTML5
CSS3
JavaScript
